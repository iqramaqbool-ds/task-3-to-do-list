# To-Do List CLI

A beginner-friendly Python command-line To-Do List application.

## Features

- Add new tasks
- View all tasks
- Delete tasks
- Prevent empty tasks
- Handle invalid task numbers
- Simple interactive menu

## Technologies Used

- Python
- Command Line Interface (CLI)

## How to Run

Run the following command:

python todo.py

## How It Works

The program displays a menu where users can:

1. Add a task
2. View tasks
3. Delete a task
4. Exit the application

Tasks are stored in a Python list while the program is running.
